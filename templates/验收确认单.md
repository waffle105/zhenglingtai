# 验收确认单（督查验收司产物）

> **使用对象**：政令台在验收阶段填写。对照《政令任务书》逐条自检，**门下省式封驳**。
> **门禁硬约束**：结论非"达标" → 禁止宣称交付完成，带偏差清单打回执行工坊。重复打回 ≥ 3 次 → 升级给用户（参见 SKILL.md §2-④）。

## 为什么是这个结构

| 字段 | 解决的问题 |
|---|---|
| 结论（二分） | 验收必须落定为"达标/未达标"，让用户能立即明白能不能收 |
| 逐条对照 | 不让"看着差不多"过关——逐条可追溯 |
| 偏差清单 | 未达标时给出"差什么、怎么补"，不打回空话 |
| 主观确认项 | 把 AI 不擅判的（文风/创意）和机器能判的**分开**——主观项**绝不**算"达标" |
| 交付物 | 显式列出真正落地的文件——可被用户复查 |

---

## 字段规范

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `结论` | enum{达标, 未达标} | ✅ | 二分；未达标必须带偏差清单 |
| `逐条对照` | list[{条件, 状态, 偏差?}] | ✅ | 机械对照任务书 Accept 字段的每一项 |
| `偏差清单` | list[{条款, 差什么, 怎么补}] | ✅（结论为"未达标"时必填） | 给执行工坊的明确工单 |
| `主观确认项` | list[{维度, 用户决策}] | ✅（可空） | AI 不擅判；勾完才算真达标 |
| `交付物` | list[{path, type, summary}] | ✅ | 真实产出路径，便于复查 |

---

## 模板

```markdown
# 验收确认单 · <政令标题>

- **结论**：<达标 / 未达标>

- **逐条对照**（对照任务书 Accept）：
  - [✔] <条件 1：达标，简要依据>
  - [✔] <条件 2：达标，简要依据>
  - [✘] <条件 3 - 偏差：缺什么 / 数字不足 / 出处未给>
  -（每一条都引用回任务书的 Accept 条款，做到可追溯）

- **偏差清单**（仅结论=未达标时填）：
  - <条款 3>：<差什么> → <建议补救，如"补充 2024 年营收数据并标注来源">
  - <条款 5>：<差什么> → <建议补救>

- **主观确认项**（AI 不擅判，需用户勾；不勾不算真达标）：
  - 文风是否符合预期？<需用户确认>
  - 创意/质量是否达标？<需用户确认>
  - 结论是否符合我的真实意图？<需用户确认>

- **交付物**（落政令档/交付物/，如有）：
  - <路径 1 · 类型 · 一句话摘要>
  - <路径 2 · 类型 · 一句话摘要>

---

*门禁硬约束：*
*1. 结论非"达标" → 禁止宣称交付完成。*
*2. 主观项未勾 → 标注"待用户确认"，结论仍可写"达标（机器项）"。*
*3. 反复打回 ≥ 3 次 → 升级给用户，列出卡点和历史偏差，不无限循环。*
```

## 达标示例（所有条件通过）

```markdown
# 验收确认单 · 竞品分析示例

- **结论**：达标

- **逐条对照**（对照任务书 Accept）：
  - [✔] md 含 A、B 双方案例维度对比（4 个维度齐全）
  - [✔] 关键数据有出处（8 处引用，链接可用）
  - [✔] PPT 页数 = 12 ≥ 10，含"结论与建议"页
  - [✔] 交付路径落 `交付物/`：`竞品分析.md`、`竞品分析.pptx`

- **主观确认项**：
  - 文风是否符合预期？<需用户确认>

- **交付物**：
  - `交付物/竞品分析.md` · md · A/B 4 维度对比
  - `交付物/竞品分析.pptx` · pptx · 12 页汇报版
```

## 未达标示例（打回执行工坊）

```markdown
# 验收确认单 · 竞品分析示例

- **结论**：未达标

- **逐条对照**：
  - [✔] md 含 A、B 双方案例维度对比
  - [✘] 关键数据有出处 — 偏差：3 处营收数据未给来源
  - [✔] PPT 页数 ≥ 10
  - [✘] 结论与建议页缺'  — 偏差：PPT 末页只有总结没有建议

- **偏差清单**：
  - 条款 2：3 处营收数据未给来源 → 补年报链接或公开数据截图并标注
  - 条款 4：PPT 末页加 "建议" 小节，≥ 3 条具体行动项

- **主观确认项**：
  - 文风是否符合预期？<等用户对机器项确认后再问>

- **交付物**（暂列，不算交付完成）：
  - `交付物/竞品分析.md` · md · 待补 3 处出处
  - `交付物/竞品分析.pptx` · pptx · 待补末页建议
```

## 验证：升级给用户的触发条件

- 同一政令被验收打回 ≥ 3 次仍无法达标
- 触发现：政令台停下整条流水线，列出历史偏差 + 卡点分析，请用户决策"换思路 / 降级 / 取消"
- 防止 AI 陷入"反复重做但结果一样"的死循环
