# 执行工序单（流转司产物）

> **使用对象**：政令台在流转阶段填写。读【技能登记册】后产出；门禁：未产出 → 执行工坊不得开始。
> **来源约束**：所有 `skill_id` 字段必须从登记册运行时聚合中存在的 skill 中选；找不到的填 `（无登记）` 并触发通用模式（参见 SKILL.md §3.4）。

## 为什么包含这些字段

| 字段 | 解决的问题 |
|---|---|
| 路由结论 | 把"这条政令打算派给谁"显式定格——便于事后追溯"为什么这个 skill 来干" |
| 工序 | 把派发落实成步骤，让 AI 不能"装作按工序做" |
| 验收点 | 每步的"出口"标准——是验收司封驳的依据 |
| 停顿点 | 把"需要用户拍板"的中间态显式标出，避免 AI 自行决定 |
| fallback | skill 不可用时提前想好兜底，减少临时起意的偷懒 |

---

## 字段规范

| 字段 | 类型 | 必填 | 含义 |
|---|---|---|---|
| `路由结论.主 skill` | skill_id string | ✅ | 最高分候选，未找到填 `(无登记)` |
| `路由结论.协同` | list[skill_id] | ✅（可空） | 次高且分接近的候选，输出文件型互补时填 |
| `路由结论.委托 meta` | skill_id | ✅（可空） | 若整条政令委托给 `is_meta: true` skill，填它 |
| `工序` | list[工序条目] | ✅ | 顺序的步骤；每条目含 `step / skill / input / output / 验收点` |
| `停顿点` | list[step_idx] | ✅（可空） | 哪些步骤后需用户确认 |
| `fallback` | object `{skill_id → 兜底策略}` | ✅（可空） | 各 skill 不可用时的备选 |

---

## 模板

```markdown
# 执行工序单 · <政令标题>

- **路由结论**：
  - 主 skill：<skill_id | (无登记)>
  - 协同：<[skill_id_a, skill_id_b]，可空>
  - 委托 meta：<skill_id，可空；若非空则本表仅在通译/验收两头参与，中间整条委托该 skill>

- **工序**（按顺序）：
  1) `[step 1]` `[调 skill: <id>]` 输入=<素材/路径> → 产出=<路径/类型>
     - 验收点：<该步可验证的出口，如"文件存在且非空">
  2) `[step 2]` `[调 skill: <id>]` 输入=<…> → 产出=<…>
     - 验收点：<…>
  3) `[step 3]` `[调 skill: <id 或 "(无登记)">]` 输入=<…> → 产出=<…>
     - 验收点：<…>
  -（每一步的"验收点"必须独立可验证，否则验收司无依据封驳）

- **停顿点**：<哪些步骤后需用户确认；空表示无需中途确认>
  - <例如：步骤 1 后确认清洗无误再写文案>

- **fallback**：
  - skill A 不可用 → 改用 Python 直接处理并显式说明
  - skill B 不可用 → 退回 markdown 单产出并标注"无 PPT 版"
  - 全部不可用 → 触发通用模式：AI 直接执行，仍按工序分步

---

*门禁硬约束：工序单未产出 → 执行工坊不得开始。*
*委托 meta 字段非空 → 政令台仅承担通译+验收，中间不重复调度（参见 SKILL.md §3.5）。*
```

## 串行协同最小示例（多 skill 撞同一意图时分开了）

```markdown
# 执行工序单 · 清洗→写文案

- **路由结论**：
  - 主 skill：example-excel-clean
  - 协同：[example-sales-copy]
  - 委托 meta：（空）

- **工序**：
  1) `[step 1]` `[调 skill: example-excel-clean]` 输入=`raw.xlsx` → 产出=`clean.xlsx`
     - 验收点：`clean.xlsx` 存在、列数 ≥ 4、行去重后非空
  2) `[step 2]` `[调 skill: example-sales-copy]` 输入=`clean.xlsx` → 产出=`copy.md`
     - 验收点：md 存在、含「卖点」段、字数 ≥ 300

- **停顿点**：[1]（步骤 1 后请用户确认清洗无误再写文案）

- **fallback**：
  - example-excel-clean 不可用 → Python + openpyxl 直处理并说明
  - example-sales-copy 不可用 → 用通用 write_copy 替代
```
